# Recon

This directory holds the Phase 0 reconnaissance notes — surveys of
related literature, tooling we considered or rejected, and notes from
inspecting representative FITS frames.

The Phase 0 notebook lives outside the package tree (it pulls in
external data and is not intended to be reproduced by readers
without the corresponding archive credentials). A pointer will be
added here once that notebook is ready to share.

For the published, runnable hello-world, see
[`tutorials/01_hello_world.ipynb`](../tutorials/01_hello_world.ipynb).
