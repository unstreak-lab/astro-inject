# astro-inject

Inject synthetic artifacts into astronomical images for ML training
and pipeline evaluation.

This site is the canonical documentation for **astro-inject**. It is
generated from the source tree with [MkDocs Material] and pulls API
docs directly from the package docstrings.

## Where to start

- **Design:** the [Design overview](design/astro-inject.md) describes
  the architecture and the contracts between modules.
- **Tutorials:** the [hello-world notebook](tutorials/01_hello_world.ipynb)
  takes you from "the package is installed" to "I see an astronomical
  image render inline".
- **References:** the [References page](references.md) lists the papers
  and tools that informed this project.
- **Decisions:** every non-trivial architectural choice has an
  [ADR](decisions/000-template.md). Start with the template to see the
  format.

## Status

Pre-alpha. The public API is not yet stable; only the visualization
helper is fully implemented in the current scaffold.
