FITS header:
    Has information about camera, filter, exposure etc.
WCS (World Coordinate System):
    Part of the header, tells which point in the sky each pixel is looking at, giving information like how big each pixel is in the sky.
Pixel scale
    How much of the sky the pixel covers.
Seeing
    Blob width for a blurry star due to atmosphere.
PSF FWHM
    Blob shape, blob width.
Sky background / sky level
    Baseline brightness for the sky, the sky is not perfectly black.
Bandpass / band / filter
    For a camera, the wavelenghts the instrument operates in.
Zero point
    Conversion factor between raw counts and magnitude.
Gain
    Photos to pixel value, gain of the instrument.
Nominal value
    Spec sheet default.
